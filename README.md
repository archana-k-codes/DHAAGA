# DHAAGA — Business Requirements Document (BRD)

## 1. Project Information

Project Name: Dhaaga
Business Type: Tailoring & Boutique
Project Type: Online Tailoring Management Website
Target Market: Local Customers
Location: Pani Ki Tanki, Shastri Nagar, Jaipur, Rajasthan


## 2. Business Overview

Dhaaga is a local tailoring and boutique business that provides stitching, alteration, and clothing finishing services. The website will allow local customers to explore services and submit tailoring booking requests online.


## 3. Services Offered

1. Saree Pico-Fall

2. Designer Blouse Stitching

3. Clothes Alteration

4. Blouse Fitting

5. Suit Stitching

6. Lehenga Stitching

7. Fall and Edging

8. Other Tailoring Work

## 4. Business Rules

Customers can submit booking requests through the website.
Customers must bring their clothes to the shop.
Some services will have fixed prices.
Custom designs and requirements may have custom prices.
The owner will review each booking before confirming it.
Each booking will receive a unique Booking ID.
Customers will use their Booking ID and mobile number to track orders.
